# TanStack Query

## Projenin Amacı
React kullanarak API'den kullanıcı verilerini çekmek ve TanStack Query ile yönetmek.

## Kullanılan Teknolojiler
- React
- Vite
- TanStack Query
- JSONPlaceholder API

## Özellikler
- API'den kullanıcı verilerini çekme
- Kullanıcıların ad, e-posta ve şehir bilgilerini listeleme
- Yüklenme ve hata durumlarını yönetme
- API verilerini önbellekleme

## Çalıştırma
```bash
npm install
npm run dev
```
