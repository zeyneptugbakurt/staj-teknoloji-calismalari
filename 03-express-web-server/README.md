# Express.js Web Sunucusu

Node.js ve Express.js kullanılarak geliştirilen basit bir web sunucusu.

## Özellikler
- Ana sayfaya GET isteğiyle cevap verir.
- Hakkımda sayfası sunar.
- HTTP isteklerini ve cevaplarını temel düzeyde gösterir.

## Kullanılan Teknolojiler
- Node.js
- Express.js

## Çalıştırma
npm install
node index.js

## Adresler
- http://localhost:3000
- http://localhost:3000/hakkimda
