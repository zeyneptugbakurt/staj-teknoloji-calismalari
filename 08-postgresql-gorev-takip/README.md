# PostgreSQL Görev Takip Sistemi

PostgreSQL 18 kullanılarak geliştirilen basit bir görev takip veritabanı projesidir. SQL komutlarıyla görev oluşturma, görevleri listeleme ve görev durumunu güncelleme işlemleri gerçekleştirilir.

## Özellikler

- Görev tablosu oluşturma
- Yeni görevler ekleme
- Görevleri listeleme
- Görevi tamamlandı olarak işaretleme
- Otomatik ID ve oluşturulma tarihi

## Kullanılan Teknolojiler

- PostgreSQL 18
- SQL

## Veritabanı Tablosu

`gorevler` tablosunda şu alanlar bulunur:

| `id` |

| `baslik` | 

| `aciklama` |


| `olusturma_tarihi` |

## Kullanılan SQL İşlemleri

- `CREATE TABLE`: Görev tablosunu oluşturur.
- `INSERT INTO`: Yeni görev kayıtları ekler.
- `SELECT`: Görevleri listeler.
- `UPDATE`: Görev bilgilerini günceller.

## Örnek Görevler

- PostgreSQL öğren
- SQL pratiği yap

## Amaç

İlişkisel veritabanı yönetimini, temel SQL komutlarını ve veri ekleme, listeleme ve güncelleme işlemlerini öğrenmek.
