# TypeScript Kullanıcı Bilgisi

TypeScript ile geliştirilmiş basit bir kullanıcı bilgisi uygulamasıdır.

## Özellikler

- Kullanıcı adı, yaş ve öğrenci durumunu tutar.
- TypeScript tür tanımlamalarını kullanır.
- JavaScript'e derlenerek çalıştırılır.

## Çalıştırma

```bash
npm install
npm run build
npm start
```
