# Prisma ile Veritabanı İşlemleri

Node.js ve Prisma ORM kullanılarak geliştirilen basit bir öğrenci kayıt uygulamasıdır.

## Özellikler
- Öğrenci ekleme
- Öğrencileri listeleme
- E-posta adresine göre öğrenci arama
- Öğrenci bilgilerini güncelleme
- SQLite veritabanı kullanımı

## Kullanılan Teknolojiler
- Node.js
- Prisma ORM
- SQLite
- JavaScript

## Kurulum

```bash
npm install
npx prisma migrate dev
node index.js
```

## Amaç

Prisma ORM aracılığıyla veritabanı işlemlerini öğrenmek ve uygulamak.
