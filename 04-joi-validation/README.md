# Joi Veri Doğrulama

Node.js ve Joi kullanılarak geliştirilen basit veri doğrulama uygulaması.

## Özellikler
- Kullanıcıdan ad, yaş ve e-posta bilgisi alır.
- Adın en az iki karakter olmasını kontrol eder.
- Yaşın 18 veya üzerinde ve tam sayı olmasını kontrol eder.
- E-posta biçimini doğrular.

## Kullanılan Teknolojiler
- Node.js
- Joi

## Çalıştırma
```bash
npm install
node index.js
```
