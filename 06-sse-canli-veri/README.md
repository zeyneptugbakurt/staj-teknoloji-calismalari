# SSE ile Canlı Veri Akışı

Express.js ve Server-Sent Events kullanılarak
geliştirilen basit bir gerçek zamanlı veri akışı uygulaması.

## Özellikler
- Sunucu her saniye yeni sayı gönderir.
- Tarayıcı sayfayı yenilemeden veriyi gösterir.
- Bağlantı kapatıldığında zamanlayıcı temizlenir.

## Kullanılan Teknolojiler
- Node.js
- Express.js
- Server-Sent Events (SSE)

## Çalıştırma
```bash
npm install
node index.js
```

http://localhost:3001/
